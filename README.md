# 知能科学計算ツール

React + TypeScript + Vite で作成した、授業や課題向けの知能科学計算ツールです。巡回セールスマン問題（TSP）、強化学習、最適化、ニューラルネットワーク、遺伝的アルゴリズムの計算を扱います。バックエンドや外部APIは使わず、すべてブラウザ内で計算します。

## 起動方法

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run build
```

テスト実行:

```bash
npm test
```

## 計算式

### 有効な巡回経路の総数

対称巡回セールスマン問題では、開始都市を固定し、逆回りの経路を同一の経路として扱います。

```text
有効な解の総数 = (n - 1)! ÷ 2
```

大きな値でも正確に扱えるように、JavaScript の `BigInt` で計算しています。

### 2都市間の距離

2次元座標のユークリッド距離を計算します。

```text
距離 = √((x2 - x1)² + (y2 - y1)²)
```

途中計算では丸めず、最終結果だけ `toFixed(4)` で小数点以下第4位まで表示します。

### TSPの最短経路

都市1を出発地点に固定し、都市2以降の順列をすべて列挙して距離を比較します。各経路では、最後の都市から都市1へ戻る距離も必ず加えます。

都市数は全探索の処理時間を考慮して 3～10 都市に制限しています。同じ最短距離の経路が複数ある場合は、同率の経路も表示します。

## 使用方法

1. 「有効な巡回経路の総数」で都市数を入力し、対称TSPの解の総数を計算します。
2. 「2都市間の距離」で2つの座標を入力し、ユークリッド距離を計算します。
3. 「巡回セールスマン問題の最短経路」で都市数と座標を入力し、全探索で最短経路を求めます。
4. 「指定した経路の距離計算」で `1,3,2,4` または `1 → 3 → 2 → 4` の形式で訪問順を入力します。最後の `→ 1` は内部で自動的に追加されます。

## サンプルデータ

```text
都市1：(3.21, 6.54)
都市2：(9.87, 4.32)
都市3：(7.65, 0.98)
都市4：(5.43, 8.76)
```

このデータでは、最短経路の一つは `1 → 3 → 2 → 4 → 1` で、合計距離を小数点以下第4位まで表示すると `20.5444` になります。逆順の `1 → 4 → 2 → 3 → 1` も同じ距離です。

## 強化学習の計算

画面上部のメニューで「TD学習」「エピソードTD学習」「ε-greedy方策」「Q学習」「用語確認」に切り替えられます。計算結果は原則として `toFixed(4)` で小数点以下第4位まで表示します。途中計算では丸めません。

### TD学習

状態価値関数を次の式で更新します。

```text
V(s) ← V(s) + α { r + γV(s') - V(s) }
```

移動先が終端状態の場合は `V(s') = 0` として扱います。「割引率を使用しない」を選んだ場合は `γ = 1` で計算します。

### エピソードTD学習

移動順に沿って状態価値を逐次更新します。各遷移の更新後の値を、次の遷移ですぐに使うオンライン更新です。

```text
S3 → S2 → S1 → S2 → S3 → S4 → S5 → G2
```

のような矢印区切りと、`S3 S2 S1 S2 S3 S4 S5 G2` のような半角空白区切りの両方を認識します。同じエピソードを指定回数だけ繰り返す計算と、許容誤差未満になるまで繰り返す収束計算もできます。

### ε-greedy方策

探索時には選択可能なすべての行動から一様ランダムに選びます。行動数を `k`、最大価値を持つ行動数を `m` とします。

```text
対象がgreedy行動の場合: P = (1 - ε) / m + ε / k
対象がgreedy行動ではない場合: P = ε / k
```

同率最大の行動が複数ある場合にも対応しています。

### Q学習

行動価値関数を次の式で更新します。

```text
Q(s,a) ← Q(s,a) + α { r + γ max Q(s',a') - Q(s,a) }
```

移動先が終端状態の場合は `max Q(s',a') = 0` として扱います。行動選択は greedy 方策による自動選択と手動選択を切り替えられます。

### 用語確認

N本腕バンディット問題の「知識利用」と「探索」をカード形式で確認できます。答えは表示・非表示を切り替えられ、コピーもできます。

## 機械学習・最適化の計算

画面上部のメニューで「二次関数」「誤差関数」「最急降下法」に切り替えられます。いずれも途中計算では丸めず、最終表示だけ `toFixed(4)` で小数点以下第4位まで表示します。

### 二次関数

任意の二次関数に x を代入して出力を計算します。

```text
f(x) = ax² + bx + c
```

入力された関数は、係数が `1`、`-1`、`0` の場合にも読みやすい形で表示します。例えば `1x²` ではなく `x²`、`+ -6x` ではなく `- 6x` と表示します。

### 二次関数の微分

二次関数は次のように微分します。

```text
f'(x) = 2ax + b
```

画面では導関数を赤色で強調表示します。表示用の数式文字列と、内部計算に使う数値は分けています。

### 最急降下法

最急降下法では、現在の x から勾配方向へ学習率 α の分だけ移動します。

```text
x(new) = x(old) - αf'(x(old))
x(new) = x(old) - α(2ax(old) + b)
```

学習率 α は、勾配に対してどれだけ大きく動くかを決める値です。大きすぎると値が発散することがあるため、値が急激に増加している場合は警告を表示します。

複数回更新では、各回の更新後の x を次回の更新前の x として使います。更新回数は 1 以上 100000 回以下です。

### 二乗誤差

二次関数と学習データから、次の誤差関数を計算します。

```text
E = 1/2 Σ(yi - f(xi))²
```

各データについて、予測値、残差、残差の二乗、誤差への寄与を表で表示します。予測値や残差は途中で丸めず、最後の E だけ小数点以下第4位まで表示します。

### 学習データの入力方法

学習データは表から1件ずつ追加・削除できます。一括入力欄では次の形式を認識します。

```text
0,3
3,7
```

```text
0 3
3 7
```

```text
(0, 3), (3, 7), (7, 2)
```

## サンプル

最急降下法のサンプルAは `f(x) = 3x² - 6x - 9`、`x = 1.48`、`α = 0.1`、更新1回で `1.1920` になります。

最急降下法のサンプルBは `x = -2`、`α = 0.1`、更新4回で `0.9232` になります。

二次関数のサンプルCは `f(x) = -0.5x² + 5x - 2.5`、`x = 3.14` で `8.2702` になります。

誤差関数のサンプルDは学習データ `(0,3), (3,7), (7,2), (4,6), (10,-5)` で `42.8750` になります。

誤差関数のサンプルEは `f(x) = -0.2592x² + 1.7316x + 3.3090` とサンプルDの学習データで `0.7048` になります。

## ニューラルネットワークの計算

画面上部のメニューで「単純ニューロン」「活性化関数」「ステップ関数の学習」「シグモイド学習」「ニューラルネット用語」に切り替えられます。ステップ関数の出力は整数 `0` または `1`、それ以外の最終結果は `toFixed(4)` で表示します。

### 活性化関数に通す前の値

n個入力を持つ単純ニューロンでは、活性化関数に通す前の値 `z` を次の式で計算します。

```text
z = Σ(w_i x_i) - θ
```

重み `w_i` と入力 `x_i` は、表形式または一括入力で指定できます。

### ステップ関数

ステップ関数は次のように定義しています。

```text
y = 1  (z >= 0 のとき)
y = 0  (z < 0 のとき)
```

### シグモイド関数

シグモイド関数は次の式で計算します。

```text
y = 1 / (1 + exp(-z))
```

### ステップ関数ニューロンの学習式

教師データ `d` とステップ関数出力 `y` を使い、1回分の更新を計算します。

```text
w_i = w_i + α(d - y)x_i
θ   = θ - α(d - y)
```

### シグモイドニューロンの学習式

シグモイド関数では、`y(1-y)` を掛けて更新します。

```text
w_i = w_i + α(d - y)x_i y(1 - y)
θ   = θ - α(d - y)y(1 - y)
```

### 一括入力方法

重みや入力の一括入力では、次の形式を認識します。

```text
0.1, -0.2, 0.4
```

```text
0.1 -0.2 0.4
```

```text
[0.1, -0.2, 0.4]
```

```text
0.1
-0.2
0.4
```

空文字は無視しますが、数値以外、`NaN`、`Infinity` はエラーになります。重みと入力の個数が一致しない場合も計算しません。

## 遺伝的アルゴリズムの計算

画面上部のメニューで「遺伝的アルゴリズム」を選ぶと、ページ内タブで「一点交叉」「二点交叉」「奇数位置交叉」「突然変異」「最大適応度」「ルーレット選択」「トーナメント選択」「遺伝子数」「BLX-α」を切り替えられます。遺伝子列は文字列として扱うため、`0010000` のような先頭の0は削除しません。

遺伝子の位置は1番目から数えます。入力では、区切りなしの `1010101`、半角空白区切りの `1 0 1 0 1 0 1`、カンマ区切りの `1,0,1,0,1,0,1` を同じ遺伝子列として扱います。

### 一点交叉

一点交叉では、指定した交叉位置から後ろの遺伝子をすべて交換します。交叉位置は1から始まる番号です。

```text
child1 = parent1の前半 + parent2の後半
child2 = parent2の前半 + parent1の後半
```

### 二点交叉

二点交叉では、開始位置から終了位置までの遺伝子を交換します。両端の位置も交換範囲に含めます。同じ範囲で再度交換すると元に戻るため、交叉後から交叉前を復元する場合も同じ処理を使います。

### 奇数位置交叉

奇数位置交叉では、1番目、3番目、5番目、7番目のような奇数位置の遺伝子だけを交換します。偶数位置の遺伝子は元の個体の値を維持します。

```text
親1: 1010101
親2: 1110000
交換位置: 1, 3, 5, 7
子1: 1010000
子2: 1110101
```

内部処理は汎用的な位置指定交叉として実装しており、偶数位置やユーザー指定位置にも対応しています。

### 突然変異

突然変異では、指定された位置の二進数遺伝子を反転します。

```text
0 → 1
1 → 0
```

例えば `0010111` の1番目と5番目を突然変異させると、`1010011` になります。指定していない位置は変更しません。同じ位置を複数指定した場合は重複を除いて計算します。

### 理論上の最大適応度

指定されたビット数の遺伝子を符号なし2進数として整数 `x` に変換し、すべての組み合わせを全探索して最大の適応度を求めます。ブラウザが固まらないように、全探索のビット数は20以下に制限しています。

```text
0000000 → 0
0000001 → 1
0000010 → 2
1111111 → 127
```

適応度関数は次の二次関数です。

```text
f(x) = ax² + bx + c
```

サンプルでは `a = 1`、`b = -20`、`c = 10` として、次を計算します。

```text
f(x) = x² - 20x + 10
0 ≦ x ≦ 127
f(127) = 127² - 20×127 + 10
       = 16129 - 2540 + 10
       = 13599
```

このため、7ビットのサンプルでは理論上の最大適応度は `13599`、整数 `x` は `127`、対応する遺伝子列は `1111111`、組み合わせ数は `128` です。

### ルーレット選択

ルーレット選択では、適応度に比例して個体が選ばれる確率を計算します。

```text
P(i) = fitness(i) / Σfitness
```

適応度は0以上の有限数で、適応度の合計が0の場合は計算できません。

### トーナメント選択

トーナメント選択では、集団から抽出した複数個体のうち、最も適応度が高い個体を選びます。同率最大がある場合は、同率の個体をまとめて表示します。乱数シード付きのランダム抽出にも対応しています。

### グループ分け問題の遺伝子数

講義方式に合わせて、人数以上となる最小の2の累乗を遺伝子数として使います。

```text
geneCount = 2^ceil(log2(numberOfPeople))
```

### BLX-α

実数値遺伝的アルゴリズムの交叉範囲を次の式で計算します。

```text
minParent = min(x1, x2)
maxParent = max(x1, x2)
I = maxParent - minParent
lower = minParent - αI
upper = maxParent + αI
average = (lower + upper) / 2
```

平均値は親遺伝子2つの中点と等しいため、αを変更しても変わりません。

## 用語・確認問題

強化学習、ニューラルネットワーク、遺伝的アルゴリズム、最適化の用語は「用語・確認問題」ページに統合しています。カテゴリ絞り込み、キーワード検索、答え入力による正誤判定、答えの表示・非表示、コピー、前後移動、ランダム出題に対応しています。用語データは `src/data/knowledgeTerms.ts` で一元管理しています。

遺伝的アルゴリズムのカテゴリでは、基本用語として「個体」「遺伝子」「適応度」「選択」「交叉」「突然変異」を確認できます。これらの問題も独立ページには分けず、すべて同じ「用語・確認問題」ページで管理・検索・出題されます。
